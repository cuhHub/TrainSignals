# cuhHub - Train Signals

## 📚 Overview
An addon providing train signals around the map. Ripped from base-game train signals addon.

## ⚙️ Setup
⚠️ [cuhkit](https://github.com/cuhHub/cuhkit) is required.

1) Run `git clone https://github.com/cuhHub/TrainSignals`.
2) Run `cuhkit setup`.
3) Run `cuhkit build`. Do this for every change to the code.
4) Run the addon in a save and all should work.
